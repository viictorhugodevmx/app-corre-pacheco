# APP Corre, Pacheco

- Producto: runner infinito, versión 0.1.
- Modo: Lab, Metodología APP v0.1.
- Objetivo: reforzar React mediante un juego funcional y visualmente atrapador.
- Entorno: Ubuntu, Node 22.19.0 y npm.
- Arquitectura: React para interfaz; Canvas para mundo y animación.
- Datos: partida en memoria; récord local en localStorage.
- Recursos gráficos: creados con código propio, sin recursos externos.
- Repositorio previsto: app-corre-pacheco.
- Entrega: GitHub y Netlify.

## Alcance

Carrera automática, salto simple, cigarros y ceniceros como obstáculos,
hojitas coleccionables, dificultad limitada, puntos, récord,
pausa, derrota y reintento. Teclado y controles táctiles.

La motita es una guía visual de la persecución; no se alcanza en v0.1.

## Dirección visual

Cartoon arcade, atardecer morado, verdes vivos y acentos cálidos.
Personaje expresivo, escenario con profundidad, animaciones y partículas.
El acabado visual forma parte de la aceptación.

## Pospuesto

Audio, poderes, doble salto, skins, obstáculos aéreos,
niveles, backend, cuentas y ranking online.
